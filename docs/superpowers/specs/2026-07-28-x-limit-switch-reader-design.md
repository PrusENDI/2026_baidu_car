# X 轴微动开关读取脚本设计

## 目标

阶段一只增加一个无电机动作的 MC602 模拟传感器读取脚本，用于在 Orin 现场采集 X 轴 COM+NC 微动开关的松开值和按下值。脚本不得创建机械臂控制器、不得发送电机或舵机命令，也不得修改 X 轴零点。

## 已确认边界

- 控制器为 MC602，读取沿用已验证的 `AnalogInput` 路径，即 `dev_id=0x07`、`mode=0`。
- P4、P5 当前空闲；脚本通过必填 `--port` 选择，不擅自固定其中一个。
- 开关接线改为 COM+NC。按下时触点断开，但原始模拟值升高或降低仍需现场测量。
- Y 轴使用的 P6 和车辆四键使用的 P1 不作为脚本默认端口。
- 本阶段不修改 `reset_x()`、`arm_cfg.yaml`、舵机 angle16 协议或任何运动逻辑。
- 用户明确要求本阶段不新增或运行测试。

## 命令行接口

脚本路径为 `tools/read_x_limit_switch.py`。

必填参数：

- `--port PORT`：MC602 传感器端口；现场先使用 4 或 5。

可选参数：

- `--interval SECONDS`：采样间隔，默认 `0.1` 秒，必须大于零。
- `--threshold VALUE`：现场取得两组原始值后设置的判定阈值。
- `--active above|below`：原始值高于/低于阈值时视为开关触发。
- `--stable-samples COUNT`：显示稳定触发所需连续样本数，默认 5，必须大于零。

`--threshold` 与 `--active` 必须同时提供或同时省略。省略时输出原始值并将判定标为 `UNCONFIGURED`；提供时输出 `TRIGGERED`、`RELEASED` 以及连续触发计数。

## 数据与错误处理

脚本启动后明确打印“只读传感器诊断、不会发送运动命令”。每行包含时间戳、端口、原始值、判定状态、连续触发计数和是否已达到稳定触发。

MC602 当前 `send_get()` 在本次无响应时会返回设备对象缓存的上一次值。为避免把旧值当作本次采样，脚本在每次调用高层 `AnalogInput.read()` 前将当前 MC602 AnalogInput 实例的 `last_data` 清空。若本次事务超时、返回不可解析数据或得到非有限数值，输出 `ERROR`，不沿用旧值，并清零连续计数。

脚本必须确认当前控制器是 MC602；若不是则报错退出。`Ctrl+C` 正常结束循环。脚本没有任何停止电机逻辑，因为它从不实例化或调用电机接口。

## 现场使用流程

1. 确认主车程序已停止，避免两个进程同时轮询共享串口。
2. 将 COM+NC 开关接到确认空闲的 P4 或 P5。
3. 不提供阈值运行脚本，分别记录松开、按下和断开导线时的原始值范围。
4. 选择位于松开/按下区间之间且留有噪声裕量的阈值，确定 `above` 或 `below`。
5. 带阈值重新运行，确认松开为 `RELEASED`、按下为 `TRIGGERED`，断线呈现预期的失效安全状态。

## 阶段二输入

阶段二只有在用户提供最终端口、松开值范围、按下值范围、断线值范围、有效方向和阈值后才修改 `arm_cfg.yaml` 与 `reset_x()`。
