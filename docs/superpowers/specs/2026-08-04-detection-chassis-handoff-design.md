# 视觉对齐底盘接管设计

## 目标

将 7_17 版本的横向底盘接管能力同步到当前 `move_to_detection_target()`：机械臂 X 轴到达安全边界且视觉控制仍要求继续越界时，停止机械臂并由底盘横移完成同方向的视觉校准。

## 行为

- 调用方提供 `arm_x_bounds` 时使用该边界；未提供时使用 7_17 默认边界 `(0.01, 0.24)`。
- 下界处仅在 `out_y < 0` 时接管，上界处仅在 `out_y > 0` 时接管；回到安全区的控制仍由机械臂执行。
- 接管时返回机械臂输出 `0` 和底盘横移输出 `-out_y`。
- 未接管、目标丢失、对齐完成、停止请求或超时时，底盘横移输出为 `0`。
- 当前固定靶关联、相机中心补偿、超时诊断和返回值保持不变。

## 验证

从源码 AST 中提取真实静态方法，测试默认边界、自定义边界、上下界接管方向以及回到安全区的非接管方向；另检查主循环确实将横移输出传入 `set_velocity()`。
