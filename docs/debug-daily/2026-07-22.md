## 播种右侧抓取与放置位置

`auto_seeding()` 的第二轮右侧抓取增加并保留以下安全和遥测行为：

- 每次旋转到 `RIGHT` 前通过 `reset_x()` 触达物理回收端并重建水平轴零点；
- 右侧预抓取水平位置为 `0.25 m`，允许范围为 `[0.24, 0.260] m`；
- 三次右侧识别前统一执行车体偏移 `RIGHT_SEEDING_PRE_DETECTION_OFFSET = [0.0, -0.06, 0.0]`；
- 偏移前后打印循环编号、目标键、偏移量和里程计坐标；
- 抓取后再次 `reset_x()`，成功后才允许旋转到 `LEFT`；
- 左侧放置前的机械臂水平补偿失败时禁止释放。

第一轮保存放置位姿时，新增最小的确定性坐标修正：

```python
corrected_x = x + 0.05 * math.cos(z)
corrected_y = y + 0.05 * math.sin(z)
pose = [corrected_x, corrected_y, z, my_car.arm.x_get_position()]
```

该修正表示沿保存位姿的车头方向前移 `0.05 m`。车身约为 45° 时，世界坐标 `x/y` 各增加约 `0.0354 m`。第二轮 `move_to_position(pose[:3])` 会直接使用修正后的放置坐标。按现场要求，本次没有为这三行最小修改新增测试；尚未进行新的实车验证。

## 侧摄像头中心校准

`config_car.yml` 新增全局侧摄像头物理偏移：

```yaml
camera_calibration:
  side_center_offset_x_m: -0.06
```

负值表示摄像头光轴相对机械中心偏左。`move_to_detection_target()` 将米制偏移按侧摄像头视场宽度 `0.33 m` 换算，并与任务自己的 `delta_x` 合成：

```text
effective_delta_x = task_delta_x - side_center_offset_x_m / 0.33
```

视觉对齐日志会打印任务目标、物理偏移和最终有效目标。该校准只在视觉闭环期间影响底盘 `dx`；第二轮返回保存的放置位姿时是纯里程计定位，因此另外增加了上述放置位姿前移 `0.05 m` 的直接修正。
