# 2026-07-14 调试记录

## 目标

- 排查 MC602 总线舵机 2 可读取状态但无法运动的问题。

## 本日操作

- 停止并禁用了旧车控的用户级 `autoStart.service`，释放旧 `car_start.py` 可能占用的控制器串口。
- 确认旧程序由 `~/.config/systemd/user/autoStart.service` 经 `/home/jetson/autoStart.sh` 启动。
- 检查总线舵机控制代码：MC602 总线舵机使用设备 ID `0x06`，公共入口为 `ServoBus(port).set_angle(angle, speed)`。
- 检查机械臂配置：总线舵机端口为 2，回中角度为 0。
- 排除并解决总线舵机的硬件问题。
- 更换新电机后，机械臂部分当前问题已解决。

## 现象与证据

- 下位机侧能够识别总线舵机 ID，并读取当前角度。
- 下发 `bus 2` 的位置控制后，舵机未发生运动。
- 此现象说明总线通信至少部分可用；尚不能据此判定舵机损坏。
- 当前明确可用的总线舵机仅为 ID 2 的中线舵机。

## 已解决

- 总线舵机的硬件问题已解决。
- 换装新电机后，机械臂部分当前问题已解决。
- ID 2 的中线总线舵机已明确可用。

## 结论

- 当前可将 ID 2 中线舵机作为已验证可用的基准通道；其他总线舵机仍需逐个验证。
- 官方说明指出，多级总线舵机需要增加降压模块，以避免 PID 过硬；该项尚未处理。
